# Documentation artwork

- `tabforge-mark.svg`: editable project mark with an amber hammer tilted 30 degrees anticlockwise and one amber cell beside a table grid.
- `foundation-model.svg`: editable main figure showing mixed-type tables, a shared pretrained TabFORGE backbone, and seven downstream tasks. Task-specific adaptation and downstream heads are identified explicitly.
- `generation.svg`, `training.svg`, `devices.svg`, `classification.svg`, `regression.svg`, `embeddings.svg`, `imputation.svg`, `clustering.svg`, `anomaly.svg`: nine distinct tutorial illustrations. Their points, curves, and cells are conceptual examples, with no benchmark results implied.
- `prediction.svg`: combined prediction illustration used by the home-page task card.
- `paper-framework.png`: web rendering of the original paper architecture figure, converted at 2400-pixel maximum dimension. Reused with the project owner's permission.
- `paper-framework.svg`: vector conversion of the same original PDF using `pdftocairo -svg`. Used for all model architecture figures in the wiki; the README uses the PNG preview and links to the vector version.
- `colab-badge.svg`: local copy of the official Open in Colab badge used by the README and tutorial gallery.

The foundation-model and tutorial SVGs are documentation illustrations. The paper figure is the source for model architecture and component terminology.

The documentation illustrations use a light blue palette and embedded dark-theme styles. Their colour scheme follows the documentation theme when embedded in the wiki. The project mark uses the theme's primary blue and amber accent. The original paper architecture figure is preserved.
